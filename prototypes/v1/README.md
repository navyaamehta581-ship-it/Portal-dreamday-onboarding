# Spotify Portal Activation Intelligence frontend

Use the [root README](../../README.md) for Node 24 setup, service configuration, tests and demonstration limits. `/` and `/activation` open the current activation workspace; `/portal` preserves the supporting fixture shell, conversation and read-only repository diagnosis.
