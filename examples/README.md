# Fictional example inputs and workflow artifacts

`workflows/scenarios.json` contains structured Node launch and constrained Java onboarding requests using V1's request model. These are test/demo inputs, not production identity or permission records.

`templates/node-launch.yaml` and `templates/java-onboarding.yaml` are browser-generated V1 artifacts retained exactly as audited. Their `./skeletons/*` references are illustrative and missing. Do not register or execute these as production Scaffolder templates. A V2 compiler PR must provide reviewed skeleton content, action-schema validation, permissions and correct file layouts first.
